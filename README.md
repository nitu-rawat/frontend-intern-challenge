# 🎓 Student Dashboard

A modern and responsive Student Learning Dashboard built using Next.js and TypeScript.

## 🚀 Features

* Responsive Dashboard UI
* Student Progress Tracking
* Learning Streak Display
* Course Completion Overview
* Modern Card-Based Layout
* Clean and User-Friendly Design
* Fast Performance with Next.js

## 🛠️ Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Framer Motion
* Supabase

## 📂 Project Structure

```text
student-dashboard/
├── app/
├── public/
├── lib/
├── package.json
├── next.config.ts
└── tsconfig.json
```

## ⚡ Installation

```bash
git clone https://github.com/nitu-rawat/frontend-intern-challenge.git

cd frontend-intern-challenge/student-dashboard

npm install

npm run dev
```

## 🌐 Local Development

The application runs locally at:

```text
http://localhost:3000
```
